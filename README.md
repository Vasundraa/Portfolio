# Vasundraa S — Interactive Portfolio

A React + Vite portfolio designed as an interactive analytics-style dashboard to showcase software development, data analytics and machine-learning work.

## Included projects

### Development
- Buyoganic — Django, Python, PostgreSQL
- Shishu Aagaar — React, Django, SQLite, Android Studio
- Cura — Software Development Internship (private source)

### Data Analytics
- FreshMart — Excel sales dashboard
- TrendKart — Excel profitability dashboard
- MediCare — MySQL / SQL healthcare analytics
- HealthPlus Care — MySQL / SQL healthcare analytics
- Novitech Manufacturing — Power BI management dashboard

### AI / ML
- EnergyMate — energy monitoring and research project

## Portfolio interactions

- Project category filtering
- Project search
- Interactive project case-study modal
- Dashboard / ERD image previews and lightbox
- Novitech multi-page dashboard gallery
- Skill-to-project mapping
- Learning-path timeline
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for deployment

```bash
npm run build
```

The production files are generated in `dist/`.

## Notes

- Cura is intentionally shown as a private project without a public code/demo link.
- The portfolio uses the supplied dashboard screenshots and ER diagrams as project previews.
- Cura's logo is loaded from the project's public GitHub raw image URL.
